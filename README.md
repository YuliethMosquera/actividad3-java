# Actividad 3 - Implementación de Clases Java

## 📌 Descripción
Este proyecto implementa una clase `Product` que representa un producto con atributos como ID, nombre, precio y stock.  
Se aplican constructores, métodos getter y setter, y el método `toString()`.

## 📂 Archivos
- `Product.java` → Clase principal
- `Main.java` → Clase de demostración

## ⚙️ Compilación
```bash
javac Product.java Main.java
